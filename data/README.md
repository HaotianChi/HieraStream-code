# Data

This tree holds dataset **adapters** and empty placement roots. Raw corpora are not redistributed.

1. Download datasets listed in the root `README.md`.
2. Place files under the corresponding `data/datasets/<name>/raw/` directory.
3. Optionally run `bash scripts/setup/download_datasets.sh`.

Adapters: `data/adapters/`. Manifests: `data/manifests/`.
